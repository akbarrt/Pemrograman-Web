# 🌐 Pemrograman Web — Semester 5

![coding banner](https://images.unsplash.com/photo-1555066931-4365d14bab8c?auto=format&fit=crop&w=1400&q=80)

Repo ini adalah **kumpulan tugas dan project kecil dari mata kuliah Pemrograman Web** (Semester 5).  
Bukan produk komersial, bukan starter template siap pakai — cuma catatan belajar dan eksperimen sambil ngoding.

---

## 📂 Apa saja yang ada di sini?

| Folder / File | Apa itu |
|---|---|
| `Fliplay/` | Project landing page **Flipplay** yang dibangun dengan HTML + Tailwind CSS. |
| `teori/` | Project praktikum teori: navbar toggle mobile, validasi form, dan pengambilan data dari Public API (JSONPlaceholder). |
| `Modul 0-SETUP.pdf` | Panduan setup awal perkuliahan. |
| `Modul 1.pdf` – `Modul 6.pdf` | Materi modul perkuliahan tiap pertemuan. |

---

## 🛠️ Tech stack yang digunakan

![web dev](https://images.unsplash.com/photo-1498050108023-c5249f4df085?auto=format&fit=crop&w=1400&q=80)

- **HTML5** — struktur halaman
- **Tailwind CSS** — styling dan tema warna (via `@tailwindcss/cli`)
- **JavaScript** — interaksi: toggle navbar, validasi form, fetch data API
- **Node.js** — hanya untuk menjalankan build Tailwind (`npm run build:css`)

## 🎯 Repo ini untuk apa?

Sebagai dokumentasi dan arsip semua tugas web programming satu semester.  
Kalau kamu juga lagi belajar HTML/Tailwind, mungkin bisa jadi referensi atau sekadar lihat-lihat bagaimana struktur project yang lain.

> ⚠️ Catatan: ini hasil belajar, jadi jangan harapkan kodenya sempurna atau siap dipakai untuk production.
